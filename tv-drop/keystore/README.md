# keystore/tvdrop.jks — chave original, comprometida

Esta é a chave com que o TV Drop foi assinado até a versão 2.11 (certificado SHA-256
`bbd1529336bd34bede4139c58e44b2250796d85f58ff26fbc65df0c85825da22`). Ela e a senha estão públicas, então
**não serve como prova de autoria**.

Ela continua aqui só porque o Android exige a chave antiga para passar a identidade para a nova (rotação v3) e
para a assinatura v2 que os aparelhos com Android 8 conferem. A chave nova nunca entra no repositório: fica nos
segredos do GitHub. Veja `docs/ASSINATURA.md`.
