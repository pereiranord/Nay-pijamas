          Como jogar

          1. Escolha uma categoria (ou toque em 🎲 Mix para misturar tudo).
          2. Em 👥 Jogadores, adicione os nomes para revezar a vez e somar pontos. Dá para salvar o grupo.
          3. Quem está na vez coloca o celular deitado na testa, com a tela virada para os amigos.
          4. Os amigos dão dicas, imitam ou fazem mímica, sem falar a palavra!
          5. Acertou? Vire a tela para cima (para o teto). ✅
          6. Quer passar? Vire a tela para baixo (para o chão). ❌
          7. Volte o celular para a testa para a próxima palavra.
          8. No fim do tempo aparece o resultado. Toque numa palavra para corrigir, se o sensor errar.

          Dá para inverter as direções, mudar o tempo, a sensibilidade e o número de rodadas em ⚙️ Configurações.
